Trialist, Day 0 to Day 14

Solution-agnostic. What they are doing, what needs to happen or how they need to feel, the pages they already see (the natural intervention surfaces), and what they are anxious about. Guardian prospect trial, 14 days, Release Autopilot included.

Doing
Welcome survey, lands on Home, pokes at the five seeded example flags.
Wants something to happen before asking anyone for anything.
Finds where to turn it on, learns it needs a GitHub org admin, either installs or asks someone.
Opens a pull request on the connected repo and waits to see what the bot does.
Deploys, then checks whether anything moved.
Decides whether to roll it out to more repos and people, and whether to buy.
Needs to happen / feel
Should see Release Autopilot framed and learn what it is in under a minute. "This is for teams like mine, and I can try it on one flag without my whole org."
Watch a release run itself on a flag nobody depends on, with no GitHub and no code. "I know what it would do to a real flag."
Prerequisites, data flow, and author of record stated before any button. "Nothing is created until a person approves."
A clear result every time, including "no flag needed." What approving does and under whose name. "It ran, I understand it, I approved it."
See the release progress, pause it, and know a metric is the only thing between Production and 100%. "Nobody clicked anything."
A number to take to the team, and the cost in units they already pay. "I know what this costs and when."
Pages they already see
Welcome survey (first-action question). Home roadmap. Flags list with seeded flags and the "SDK not connected" banner. Trial banner.
A flag's detail page (Targeting, Variations, Release tab once targeted). Install SDK page.
Settings rail. Integrations catalog. GitHub App drawer. Their inbox, if they have to ask an admin.
GitHub PR, check, bot comment. The OAuth prompt. The review page.
The flag's Release tab. Release-started email. Flags list.
Plans page via "Explore plans." Customize and Check out. Trial-ending emails.
Anxiety
Is this another thing to set up before I see any value?
Is the sample a toy? Would a real flag walk Production to 100% on its own?
I am not the GitHub org admin. Which model reads my diffs, for how long? Whose name is on the commit?
Will a bot push to my branch as me? Does the check block merge? Did it even run?
Nothing is watching Production. No Slack at GA; the team learns by email.
"Free until Feb 1" sounds like a trap. What does 1.5x mean on my invoice?

The nth engineer (invited user): know, not do

They did not choose anything; a bot commented on their PR and they may have no LaunchDarkly seat. Their whole experience is one check, one comment, one OAuth click, and one review page. Nothing here sends them to settings.

PR opened on a connected repo
Check result, always, including "no flag needed: reason". Does not block merge.
85-word comment: suggests, approve, do nothing; whose account the commit lands under
First time only: connect GitHub once. No seat? A member with flag-create permission approves; you do nothing.
Review page: why, proposed flag, release plan, now vs after merge. Approve, reject, or revert.
Merge. Release starts when deployed code evaluates the flag. Watch or pause on the Release tab.
Anxiety
Another bot in my PRs. Will it comment on drafts and dependency bumps too?
Did it even run? Today there is no result when nothing is recommended.
Is the commit going to land under my name? I want launchdarkly[bot] as author, me as co-author.
I do not have a seat. Who approves, and what happens if nobody does?
If I edit the key or maintainer, is it honoured? (Edits are dropped today.) Can I skip just this PR?
Production walks to 100% with no metric watching. Pause holds, it does not roll back.
What they need to know
Comments land in repos X only; the popover names your admin.
"Reviewed" with a reason is success too.
Approve or do nothing. Rejecting has no consequence.
One OAuth click, once. Writers cannot change the account switches.
Revert the commit or pause the release from this page.
Watch from the flag's Release tab; email when a release starts.
